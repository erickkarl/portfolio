My personal site. A terminal-style intro types my name, then the page opens on the first light of an orbital sunrise photographed from the ISS.

[![Erick Karl Volkert, senior software engineer, over an orbital sunrise](docs/preview.jpg)](https://erickkarl.dev)

It is set like a document: a serif for everything I say, a monospace for the prompt, dates and labels, and a margin column that carries section names and dates. Behind it runs a live starfield (drifting stars, shooting stars, a passing satellite, and fine stardust that trails the pointer). The technology rows drift on their own and can be dragged or swiped. Everything works with reduced motion and without JavaScript.

**Live:** https://erickkarl.dev · **Components:** https://erickkarl.dev/storybook/

Built with the same stack I use at work:

| Tool | Used for |
| --- | --- |
| Next.js 16 (App Router) + React 19 | Static export of the site |
| TypeScript | Typed content model and components |
| CSS Modules + design tokens | Styling and the single dark "orbit" theme |
| CSS animations + one IntersectionObserver | Hero entrance, scroll parallax and reveals, with native scrolling and no animation library |
| Iconify (Tabler, SVG Logos, Simple Icons) | Interface icons inlined at build; technology logos written to `public/logos` by `pnpm logos` |
| Storybook 10 | Component catalogue with a11y checks and interaction tests |
| Vitest + Testing Library | Tests for the intro, tech rows, clock, starfield math and SEO data |
| GitHub Actions | CI on every branch, deploy to GitHub Pages from `main` |

## Editing content

Everything on the page comes from [`src/content/profile.ts`](src/content/profile.ts). Change the data there; the components only render it.

## Scripts

```bash
pnpm install
pnpm dev              # http://localhost:3000
pnpm test             # Vitest
pnpm lint && pnpm typecheck
pnpm build            # static export to ./out
pnpm storybook        # http://localhost:6006
pnpm logos            # rewrite public/logos after changing the stack
```

## Structure

```
src/
  app/            layout, page, global tokens, fonts
  assets/media/   NASA photographs as JPEG (see src/content/media.ts for provenance)
  components/     Intro, Motion, SpaceField, TechStack, Experience, LocalTime, CopyEmail, SplitWords, Icon, Photo
  content/        profile.ts — all page content
public/
  logos/          technology logos, generated by scripts/logos.ts
  media/          the same photographs as AVIF
scripts/          logos.ts
.github/workflows ci.yml, deploy.yml
```

## Deployment

`deploy.yml` runs lint, typecheck and tests, builds the site (base path comes from the Pages config, empty on the custom domain), builds Storybook into `out/storybook`, and publishes to GitHub Pages.
